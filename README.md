# CAFE DE JUNCTION 🍜

Sitio web oficial de **CAFE DE JUNCTION**, restaurante de cocina asiática ubicado en 695 Burke Rd, Camberwell VIC 3124, Australia.

## 🌐 Demo en vivo
[https://TU_USUARIO.github.io/cafe-de-junction/](https://TU_USUARIO.github.io/cafe-de-junction/)

## 📄 Descripción
Página web de una sola página (single-page) construida con HTML, CSS y JavaScript puro. Incluye:
- Hero con llamada a la acción
- Sección "Sobre Nosotros"
- Menú con precios
- Galería de fotos
- Testimonios
- Blog / Noticias
- Ubicación y horario con mapa embebido
- Formulario de contacto
- Botón flotante para pedidos en línea

## 🚀 Cómo desplegar
1. Clona este repositorio.
2. Abre `index.html` en tu navegador para verlo localmente.
3. Para publicarlo en GitHub Pages: ve a **Settings → Pages** y selecciona la rama `main` como fuente.

## 🖼️ Imágenes
Las imágenes actuales provienen de [Unsplash](https://unsplash.com). Si deseas usar fotos propias, reemplaza las URLs en el archivo `index.html` por las rutas de tus imágenes locales (ej. `images/mi-foto.jpg`).
